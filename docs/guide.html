Безкоштовні агенти для Claude Code

Claude Code лишається головним: планує, вирішує й перевіряє. Рутину (прочитати багато файлів, написати чернетку, порівняти варіанти, перша версія коду) він віддає безкоштовним агентам. Так ліміт підписки Claude йде на рішення, а не на обсяг.

Ви — дії, які робить людина. Claude — дає промпт, решту Claude Code робить сам. GPU — витрачає квоту Kaggle.

1Акаунти й ключі

Ви
  • Claude Code — підписка Claude (Pro або Max).
  • OpenRouter — openrouter.ai → Keys → Create Key. Безкоштовні моделі мають суфікс :free: ≈20 запитів на хвилину, 50 на день; після разового поповнення на $10 — 1000 на день (самі запити й далі безкоштовні).
  • Nous Portal — для Hermes; вхід через браузер під час встановлення.
  • Kaggle — kaggle.com, Settings → Phone verification (без цього немає GPU), потім Settings → API → Create New Token.
  • За бажанням: Google AI Studio (ключ Gemini), NVIDIA Build (≈40 запитів на хвилину), два Telegram-боти від @BotFather.
Ключі ніколи не вставляйте в чат з Claude і не комітьте. Їх кладуть у файл keys.env (він у .gitignore) або вводять у самій програмі (/connect в OpenCode). Безкоштовні тарифи можуть навчатися на ваших запитах: паролі, особисті дані й закритий код туди не відправляйте.

Ви Claude

PowerShell від адміністратора, потім перезавантаження:

Звичайний PowerShell:

Промпт для Claude
Налаштуй усе за CLAUDE.md цього репозиторію: OpenClaw, Hermes, безкоштовні моделі з ланцюжками запасних, MCP-мости ask_hermes і ask_openclaw.
Ключі я впишу сам у keys.env — скажи, коли. Усе, що потребує моїх рук (майстер у треї, вхід у Nous Portal, боти), проси окремим кроком.
Наприкінці — таблиця стану: що працює, перевірено живим запитом, що ні.

Що попросить Claude: пройти майстер OpenClaw Companion у треї, увійти в Nous Portal, вписати ключі, натиснути «Дозволити», коли OpenClaw читає файли Windows.

3OpenCode з безкоштовними моделями OpenRouter

Ви Claude

OpenCode — термінальний агент, схожий на Claude Code, але з будь-якою моделлю. Claude Code може викликати його сам однією командою і отримати готовий результат.

Термінал (будь-яка система з Node.js)
npm install -g opencode-ai
opencode auth login        # оберіть OpenRouter і вставте ключ (у програму, не в чат)
Промпт для Claude
Підключи OpenCode як безкоштовного помічника.
1) Перевір `opencode --version` і що провайдер OpenRouter авторизований (`opencode auth list`).
2) Склади список доступних безкоштовних моделей (`opencode models openrouter | grep ':free'`) і перевір 3 з них коротким запитом
   через `opencode run -m openrouter/<модель> "..."`: час відповіді і чи відповідь осмислена. Обери основну й дві запасні.
3) Допиши в мій глобальний ~/.claude/CLAUDE.md розділ «Делегування OpenCode»: які задачі віддавати (чернетки коду, тести за зразком,
   перегляд багатьох файлів), як викликати (`opencode run -m ... "задача"` у теці проєкту, read-only, якщо не просив змін),
   що не віддавати (секрети, push, деплой, фінальні рішення) і що кожну відповідь ти перевіряєш сам.
   Перш ніж записати, покажи мені текст розділу.

Перевірка: попросіть Claude «віддай OpenCode написати тести для файлу X і перевір їх». Він має запустити OpenCode, прогнати тести й сказати, що виправив сам.

4kagent: модель на безкоштовному GPU Kaggle

Ви Claude GPU

У вашому ноутбуці Kaggle запускається Ollama з моделлю Qwen3-Coder 30B на двох Tesla T4. Claude Code звертається до неї через інструменти MCP: kaggle_start, ask_kaggle, kaggle_session_ask (робоча сесія з файлами), kaggle_stop. Ядро саме вимикається після простою, щоб не їсти квоту.

Код — у репозиторії mstekh/kaggle-projects, тека claude-kaggle-bridge (доступ дає власниця репозиторію). Покладіть токен Kaggle у теку .kaggle домашньої теки, клонуйте репозиторій і запустіть claude у ньому.

Промпт для Claude
Підключи kagent за розділом «Підключити до Claude Code як інструмент (MCP kaggle)» у claude-kaggle-bridge/README.md.
Мій логін Kaggle: [логін]. Токен уже лежить у ~/.kaggle — не читай його вміст і не виводь.
1) Python ≥ 3.11 з пакетом kaggle (окреме віртуальне середовище), `kaggle kernels list --mine` має працювати.
2) Ядро — під моїм акаунтом: KAGGLE_SERVE_ID=[логін]/claude-kaggle-serve і id у kernel_serve/kernel-metadata.json.
3) npm install у claude-kaggle-bridge/mcp, `claude mcp add -s user kaggle ...` з потрібними змінними, `node selftest.mjs` без GPU.
4) Живий запуск (≈6 хв квоти GPU) — лише після мого «ок»: kaggle_start → дочекатися ONLINE → один ask_kaggle → kaggle_stop.
5) Допиши в ~/.claude/CLAUDE.md правило: великі чернетки й рутину спершу віддавати kagent (kaggle_session_ask, одна сесія на задачу),
   потім перевіряти; kagent вигадує деталі й підробляє складні задачі, тож перевіряти версії, прапорці й чи код справді робить роботу.
   Перш ніж записати, покажи мені текст.
Холодний старт ядра коштує ≈6 хв квоти. Тому MCP ніколи не вмикає ядро сам: лише за kaggle_start. Квота — ≈30 год GPU на тиждень на акаунт.

?Якщо щось не так

  • 429 / rate limit — вичерпано безкоштовний ліміт провайдера. Агенти самі переходять на запасні моделі, бо на 429 провайдер ставить паузу (у Nous бувало до 34 хв). Не запускайте більше 2–3 запитів на агента одночасно.
  • Модель OpenRouter зникла — безкоштовні моделі ротуються; попросіть Claude оновити список.
  • kagent не стартує — Kaggle без підтвердженого телефону або вичерпана тижнева квота GPU (kaggle_status скаже).
  • Агент звітує «готово», а код нічого не робить — так буває з безкоштовними моделями; саме тому Claude перевіряє кожну відповідь тестами.
  • Пастки, на які вже наступили: docs/pitfalls.md; результати моделей: docs/free-models.md.
